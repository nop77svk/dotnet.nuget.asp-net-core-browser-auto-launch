# ASP.NET Core browser auto-launch

Allows you to automatically launch your Web UI (e.g., Blazor frontend) automatically even without Visual Studio's launch settings.

## Features

- Open source and free to use.
- Available on NuGet for easy integration into your projects.

## Supported platforms

- .NET 10
- .NET 8
